# 快速切换墙纸与复原（本机预览工具）

不必手动切换 Space。默认处理显示器 1 的桌面 1、2，把已经生成的 Scene 静帧设为系统过渡底图；复原使用切换前的完整壁纸记录，包括航拍 assetID、配置和图片选项。Scene 动态播放仍由原软件负责，本工具不启动或停止它。

## 双击入口

- `快速切换底图.command`：备份原记录，然后应用底图。
- `恢复原壁纸.command`：恢复上一轮记录；也可在定时等待期间提前复原。
- `临时切换60秒.command`：应用底图，60 秒后自动复原；Ctrl+C 或正常终止也会进入复原。

默认图片为项目 `dist/SpaceTransitionDiagnostics/scene-transition.heic`，来自样本 1000000001 的真实离屏帧。它是静态过渡底图，包含捕获时的时钟；不能当成动态壁纸播放器。缺少图片时明确报错，不会改设置。

首次执行如缺少 Space 查询程序会自动编译，需要本机已有的 Command Line Tools。已在本机编译完成。脚本由 Terminal 运行，若 macOS 提示访问相关文件，按系统实际提示处理。

## 命令行

在本项目根目录运行：

```sh
python3 工具/快速墙纸/wallpaper-switch.py apply /绝对路径/图片.heic --spaces 1,2 --display 1
python3 工具/快速墙纸/wallpaper-switch.py restore
python3 工具/快速墙纸/wallpaper-switch.py timed /绝对路径/图片.heic --spaces 1,2 --display 1 --seconds 60
python3 工具/快速墙纸/wallpaper-switch.py status
```

`--spaces all` 可以选择指定屏幕的全部普通桌面；全屏应用 Space 不计入编号。编号采用调用瞬间的实时排列，macOS 自动重排可能改变编号。保存后按 UUID 复原，所以随后重排不会把原配置写错桌面。`--display` 省略时使用主屏。默认双击入口固定显示器 1，连接变化时可调整脚本或使用命令行。

## 保存与恢复

- 首次系统写入之前，完整原始 `Index.plist` 已复制到 `dist/WallpaperQuickSwitch/<时间>/original.plist`，并记录 SHA-256。
- `dist/WallpaperQuickSwitch/session.plist` 保存每个目标的原 Desktop 字段与本次写入字段；这个文件与备份必须保留至复原完成。
- 独立命令行入口只修改 `Spaces/<UUID>/Displays/<显示器UUID>/Desktop`，不写 Idle、其他桌面、全局选择或系统默认值。若全局壁纸覆盖开启、目标结构不支持或目标记录消失，会停止并报错。UI 自动模式的作用域另见下节。
- 复原会合并到最新配置中。其他桌面或屏保在期间发生的调整会被保留；若目标壁纸被用户再次更改，会报告冲突，保留恢复文件，不强行覆盖。
- 文件写入使用临时文件、fsync 和原子替换；本工具实例间加锁，写入前检查观察到的并发变化。WallpaperAgent 不遵守本工具锁，因此检查与替换之间仍有极短竞争窗口，不是系统级事务。
- 每次成功写入后仅请求重启当前用户的 WallpaperAgent 来重新载入；不重启 Dock、不修改安全设置、不操作 phonto。
- 定时等待不占用锁，“恢复原壁纸”可以提前复原。旧计时器不会恢复后来新建的会话。
- 强制杀死进程、掉电或系统刷新失败时，记录仍在，重新运行“恢复原壁纸”。没有安装后台服务，因此不能保证进程被 SIGKILL 后仍按时复原。

## 状态与限制

这是适配本机 macOS 15.8 的预览工具，使用 Apple 未公开的壁纸存储格式和只读 Space 枚举。已完成离线恢复检查；UI 自动模式另有本机短时试验。Space 动画逐帧、0.5 秒内恢复和其他系统版本的行为仍未验收。

工具的“已写入/已复原”表示配置写入完成且刷新请求已发出，不代表逐帧画面验收。0.2.10 预览已将本工具接入 WallpaperUI 的 Scene 播放/停止流程，详见下节。

实现参考是本机真实配置字段，另只读参阅 公开的 WallpaperAgent 存储字段说明。未下载或执行其代码；本工具采用逐显示器/Space 字段恢复，不采用全局覆盖和整文件回滚。


## UI 自动模式（0.2.10 预览）

设置 → Space 切换 →“自动匹配 Space 过渡底图”，默认开启。播放 Scene 时从该场景渲染器获取静帧，先保存完整原配置及字段级恢复账本，再将静帧登记为系统桌面图片并通过系统设置的“在所有空间中显示”开关刷新过渡底图。停止、换片、睡眠、退出和渲染器异常时进入复原；播放期间开关锁定。当前自动模式只支持单显示器，且会临时把该屏幕的全部普通 Space 设为同一张当前场景静帧。

首次使用需在 macOS“隐私与安全性 → 辅助功能”中允许当前 `WallpaperUI.app` 控制界面。程序只定位墙纸页标识为 `ShowOnAllDisplays` 的开关并按一次；权限缺失或系统未确认结果时停止播放并尝试恢复原壁纸。本机预览应用采用临时代码签名，重新构建后 macOS 可能要求重新授权。

打包组件位于应用 `Contents/Resources/WallpaperSwitch/`；UI使用 `~/Library/Application Support/WallpaperUI/SpaceBackdrop/` 保存持久账本和原配置，不依赖项目dist。命令的 `--state-dir` 与 `--inventory` 是子命令之前的全局选项。

内部 `lease` 命令持有独占锁，保持 stdin 打开即为使用中，EOF 或 TERM 进入复原。UI 进程被单独强制结束也会关闭管道；若辅助进程一并被杀死或掉电，仍需下次打开应用恢复。系统切到全空间模式时会清空逐 Space 记录，恢复器在校验本次静帧与原备份后重建这些原有选择；若登记图片期间系统另行删去历史 Space／非活动显示器的子节点，恢复时只保留仍存在的节点，不复活已删历史项。恢复失败不会清空账本；UI 提示恢复并暂停新的播放。检测到用户改变底图或新增 Space 时会报告冲突，不强行覆盖。原独立工具与 UI 账本独立，请勿同时操作同一桌面。

底图是启动时的静帧，时钟不会在系统底图中持续更新。当前只支持原来使用独立 Desktop 配置的一块屏幕；原有全空间壁纸、不支持的结构或多屏会报错。使用本机现有 `/usr/bin/python3`，未包含通用 Python 发行版。有关未公开格式与实际动画未经验证的边界仍适用。

离线检查：`check.py` 检查字段合并、历史节点被系统删除后的恢复和冲突保护；`check-lease.py` 使用临时配置和假UI进程检查EOF、强制结束和失败应用的回滚，不接触真实壁纸。0.2.10 的自动开关效果尚未实机复测；详见 `WE场景-阶段2BL-全空间底图确认时序修复预览.md`。


### 0.2.7逐壁纸截图修复

UI截图现由 `SceneBackdropCapture.swift` 独立模块处理：渲染器输出按实际格式解码，重新编码为真正PNG，拒绝损坏/无效输出。旧版渲染器实际输出HEIC但文件名为PNG，已修复。`Captures/<场景规范路径SHA-256>/<本次UUID>/`分别保存各壁纸各次播放的截图和source.json；不会读取上一张截图作为备用。截图按当前播放裁切生成，设置页显示当前壁纸名称及截图预览。换片先恢复原系统配置，再为新场景独立截图和应用。
